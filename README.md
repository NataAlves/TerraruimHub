# TerrariumHub

Sistema de monitoramento inteligente para terrários utilizando ESP32.

## Tecnologias

- Python
- FastAPI
- Docker
- MySQL
- Telegram Bot

## Estrutura

- app → API
- esp32 → Firmware do ESP32
- telegram_bot → Bot do Telegram
- docker → Arquivos Docker
- docs → Documentação

## Objetivo

Receber leituras do ESP32, armazenar em banco de dados e disponibilizar consultas via API e Telegram.
